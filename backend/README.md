# Backend - Pastelerias Cordova

## Pasos rápidos
1. Importar `db/scripts/db_pastelerias.sql` en MySQL Workbench para crear la BD y datos de ejemplo.
2. Configurar `src/main/resources/application.properties` si deseas cambiar usuario/clave.
3. Ejecutar desde IDE o con `mvn spring-boot:run` dentro de la carpeta `backend`.
4. Endpoints disponibles:
   - GET /api/products
   - POST /api/products
   - GET /api/products/{id}
   - PUT /api/products/{id}
   - DELETE /api/products/{id}
